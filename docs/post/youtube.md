# K2 — YouTube Content Plan (RU)

Рабочий документ для съёмки YouTube-роликов. Видео на русском языке.
См. общий план продвижения: [plan.md](plan.md).

## Общие правила

**Позиционирование:** K2 — бесплатный лёгкий мониторинг сервера (CPU/RAM/диски/сеть/процессы/Docker) в одном статическом бинарнике без зависимостей. Альтернатива тяжёлым Netdata/Grafana/Zabbix для VPS и домашнего железа.

**Хук:** первые 5 секунд — результат или боль, без приветствий («подпишитесь» в начало не ставить).

**Обложка:** тёмный фон + скриншот дашборда, крупный текст ≤4 слов, единый акцентный цвет во всей серии.

**CTA в конце каждого видео:** звезда на GitHub (мягко, одной фразой).

**Стандартные ссылки для описаний:**

```text
GitHub:   https://github.com/tashirka1/k2
Установка:
curl -fsSL https://raw.githubusercontent.com/tashirka1/k2/main/scripts/install.sh | sudo bash
```

**Базовые теги (добавлять к каждому видео):**
`k2, мониторинг сервера, server monitoring, vps, golang, htmx, netdata alternative, grafana alternative`

## Shorts (~30–45 сек)

Формат сценария: **хук** (0–3 сек) → **суть** (демо) → **CTA** (1 фраза). Описание короткое: 1 строка + ссылка на GitHub + хэштеги `#shorts #devops #linux`.

### S1. Мониторинг сервера одной командой

- **Хук:** «Весь мониторинг вашего сервера — вот эта строчка.»
- **Суть:** вставка `curl -fsSL https://raw.githubusercontent.com/tashirka1/k2/main/scripts/install.sh | sudo bash` → прогресс → открывается дашборд.
- **CTA:** «GitHub в описании.»
- **Теги:** `linux, vps, мониторинг, devops, terminal`

### S2. Этот UI работает без фреймворков

- **Хук:** «Этот сайт написан на Go. В смысле — весь.»
- **Суть:** DevTools → network: HTML отдаёт Go-сервер, ни одного JS-бандла; графики обновляются сами (htmx).
- **CTA:** «Исходники на GitHub.»
- **Теги:** `htmx, golang, web development, frontend`

### S3. VPS умирает? CPU и RAM вживую

- **Хук:** «Пока вы спите, ваш VPS может умереть.»
- **Суть:** стресс-процесс в терминале → график CPU ползёт вверх в реальном времени.
- **CTA:** «Ставится одной командой — в описании.»
- **Теги:** `linux, server, cpu, devops`

### S4. Мониторинг Docker без Grafana

- **Хук:** «Вам не нужен Grafana, чтобы видеть контейнеры.»
- **Суть:** `make up` → вкладка Containers со списком и метриками каждого контейнера.
- **CTA:** «Compose-файл в описании.»
- **Теги:** `docker, docker compose, containers, devops`
